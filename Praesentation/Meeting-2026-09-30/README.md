# DeskVision Meeting-Präsentation

Die Präsentation besteht nur aus HTML, CSS und JavaScript. Es gibt keine zusätzlichen Abhängigkeiten und keinen Build-Schritt.

## Starten

Im Projektordner:

```bash
python3 -m http.server 5517
```

Danach im Browser öffnen:

```text
http://localhost:5517/Praesentation/Meeting-2026-09-30/
```

## Bedienung

- Pfeiltasten links/rechts, Leertaste oder die Buttons unten
- `Home` springt zur ersten Folie
- `End` springt zur letzten Folie
- `O` öffnet die Folienübersicht
- Auf Touch-Geräten nach links oder rechts wischen

Über die Druckfunktion des Browsers kann die Präsentation bei Bedarf als PDF gespeichert werden.
